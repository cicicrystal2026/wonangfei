# 窝囊费 H5 V1.0.1

手机与桌面响应式的可操作体验版。原生 HTML、CSS、JavaScript，无构建依赖。发布目录为 `dist/`。

## 体验功能

- 创建、编辑一个活跃目标；目标类型为离职底气、快乐放假、奖励自己。
- 新增与编辑记录，六种事件、日期、金额、私密备注；刷新后可恢复未提交草稿。
- “其他”可输入自定义事项，勾选后设为常用；“我的 → 常用事项”可添加或移除，最多20项。历史记录保留原名称，备份包含常用事项，兼容旧版备份。
- 累计记录与自行转存标记独立汇总；修改已转存金额需重新确认。
- 删除单笔后10秒可恢复；目标归档只读；历史记录按月筛选、分页。
- 本机Canvas生成PNG战报，可隐藏金额和目标名；备注不会出现在战报。
- IndexedDB事务保存，多标签页变更通知与revision冲突检测。
- 完整JSON备份导出与导入；校验后整体替换；支持最多100目标、10000记录、5MB导入。
- 帮助、隐私说明、反馈草稿及文本下载、清空本机数据。

## 当前边界

这是可体验的前端版本，不是已经具备完整运营服务的正式商业产品。未接入账号、云同步、后台反馈、分析埋点、广告回传、收费和银行转账。未伪造发送成功、统计或支付。反馈只能存本机或下载。

业务数据只存在当前浏览器，清理或换设备不会自动恢复，请导出备份。正式推广前需补齐PRD中渠道审核、运营后台和分析授权等服务。不同域名、浏览器和设备的数据互不相通；迁移到正式域名前请导出备份。

`dist/`源码使用ES模块，请用HTTP服务器打开，不建议直接双击其中的index.html。另提供包含全部样式及脚本的独立单文件体验版；文件协议下的存储兼容性以浏览器为准，正式体验优先使用HTTPS或本地服务器。已有页面在断网后可继续本地操作；未实现离线刷新安装包或Service Worker。

## 本地启动

双击 `start-local.cmd`，或在有Node.js的终端运行：

```text
node server.mjs
```

默认 `http://localhost:4173`。设置PORT环境变量可改端口。手机和电脑在同一网络时，使用电脑局域网IP加端口访问；是否可连取决于本机网络和系统访问设置。本次QA在4178端口执行，临时QA服务器在交付时关闭，在线体验以已发布地址为准。

## 测试

```text
node --test tests/core.test.mjs
node --check dist/app.mjs
```

测试覆盖精确金额、非法输入、独立转存、重复提交、撤销恢复、进度舍入、单活跃目标、归档只读、备份往返与非法备份、日期限制、目标删除隔离。

浏览器人工交互已验证创建、首次记录、刷新持久化、转存标记、编辑重新确认、删除恢复、战报生成、隐私模式、草稿恢复与桌面/窄屏布局。使用的是本机桌面Chromium及视口模拟，未完成真实iPhone Safari、Android和小红书内嵌浏览器测试。生产前需补充真机验收。

## 文件结构

`dist/core.mjs`：纯业务规则；`dist/store.mjs`：IndexedDB事务；`dist/app.mjs`：页面、交互、Canvas战报；`dist/style.css`：响应式样式；`server.mjs`：开发预览；`tests/`：业务测试。`qa/`仅保存内部测试截图，不属于发布输出。
